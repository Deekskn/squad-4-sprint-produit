# Tests

Ce dossier regroupera les tests du produit.

## Types de tests envisagés

Selon les besoins du projet, l’équipe pourra mettre en place :

- des tests unitaires ;
- des tests d’intégration ;
- des tests fonctionnels ;
- des tests de validation des parcours utilisateurs ;
- des tests de non-régression.

## Objectifs

Les tests doivent permettre de vérifier :

- le bon fonctionnement des fonctionnalités ;
- le respect des critères d’acceptation ;
- la qualité des échanges entre le frontend et le backend ;
- la cohérence entre le produit réalisé et les besoins définis.
