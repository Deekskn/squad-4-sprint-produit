## Frontend

Ce dossier contiendra l’interface utilisateur du produit.

## Organisation prévue

L’organisation interne du frontend pourra comprendre :

`components/` : composants réutilisables ;
`pages/` : pages de l’application ;
`layouts/` : structures communes des pages ;
`services/` : communication avec l’API backend ;
`assets/` : images, icônes et autres ressources ;
`styles/` : styles globaux.
