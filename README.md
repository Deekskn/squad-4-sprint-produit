# Squad 4 — Sprint Produit

Dépôt de travail de la Squad 4 dans le cadre du Sprint Produit Akieni Academy.

## Présentation

Ce dépôt centralise les documents, le code source, les tests et les éléments nécessaires à la conception, au développement et à la présentation du produit de la Squad 4.

## Objectifs du Sprint

- Identifier un problème réel ;
- Comprendre les utilisateurs concernés ;
- Définir une solution adaptée ;
- Cadrer un MVP réalisable ;
- Rédiger les spécifications fonctionnelles ;
- Développer un produit fonctionnel ;
- Tester et valider le MVP ;
- Préparer la présentation finale et la stratégie marketing.
